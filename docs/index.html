Does this job sponsor a visa?

Paste a UK job advert. Get clean JSON and a straight answer. A 3.8 billion parameter model, tuned on one laptop GPU, and tested against pass marks that were written down before any result existed.

The honest bit

Then I tried real adverts.

How it works

Four steps, no magic.

01

Generate

2,900 synthetic adverts with known labels from original templates. Employers are fictional. Test styles never appear in training.

02

Tune

A LoRA adapter on Phi-4-mini: rank 16, two epochs, 250 steps, 3.57 GiB of GPU memory.

03

Freeze

Settings were picked on a dev split only, then written into the protocol before the test split was touched.

04

Test once

Every arm ran once on the test adverts. Failures are published as failed. Nothing was rerun.

offers

The advert says it will sponsor.

excludes

"No sponsorship", or only "must have the right to work in the UK".

unclear

Hedged wording, or two statements that contradict each other.

not_stated

Nothing about sponsorship or the right to work.

Limits

What these results do not show.

01

The test adverts are synthetic and I wrote the generator, so the tuned model learned its habits. The unseen styles reduce this but do not remove it.

02

Only 50 of the 600 test adverts were run, by decision, so the intervals are wide. The result stands as it is.

03

The real-advert set is 10 adverts, all from LinkedIn. The labels were drafted from the guide and checked by me.

04

One base model, one seed. "Unclear" is a judgement class and the rules are mine.

05

An answer says what the advert says. It is not legal advice, and a licence on the UK sponsor register does not mean a given job is sponsored.

Run it

Clone it. Check it.

The tests and the official scoring run on any laptop, with or without Docker. Training and the model need an NVIDIA GPU with 8 GB.

Open the repo Read the protocol
Quick start# tests, CPU only $ git clone https://github.com/Onkar-Gupta/sponsor-scout $ cd sponsor-scout $ pip install -r requirements.txt && pip install -e . $ pytest
Docker# re-score the saved official run $ docker build -t sponsor-scout . $ docker run --rm sponsor-scout
